# Origin 非分峰绘图格式规范 · 初稿

## 1. 用途与修改方式

用于没有分峰需求的普通科学曲线图，包括单条谱线、多样品谱线叠加，以及其他二维 X–Y 曲线。默认交付可编辑 Origin `.opju` 和一张用于检查的 PNG 预览。

本稿沿用已有规范的页面比例、Arial 字体、字号和粗黑坐标框；针对普通曲线，先拟定单曲线配色、多曲线配色、图例和 Y 轴显示规则，供用户修改。

**优先级：本次用户明确要求 > 用户修改后的第 2 节参数表 > 本文其余默认说明。** 用户已经明确的选择直接执行。第 2 节是集中修改区，若其与后文示例不一致，以第 2 节为准。

本规范默认绘制用户提供的实际数据，不自动添加分峰组分、总拟合包络或拟合背景。样式设置不授权改变原始数值。

## 3. 输入数据与曲线对应关系

### 3.1 单条曲线

最基本输入为一组 `X + Y`：

| 角色 | 示例列名 | 要求 |
|---|---|---|
| X | 自变量名称 | 读取实际单位、范围和顺序 |
| Y | 样品名或测量量名称 | 保留原值，使用真实测量单位 |

若输入项目同时含原始谱、拟合包络、组分和背景，本任务只选择用户需要的非分峰曲线。保留来源工作表中的其他数据，不因简化图页而删除原始分析结果。

### 3.2 多条曲线

可以使用共用 X 的 `X | Sample 1 | Sample 2 | …`，也可以使用各自独立的 `X1/Y1、X2/Y2、…` 或多个工作表。

- 逐条保存“样品名 → 文件/工作表 → X 列 → Y 列 → 单位 → 颜色”的映射。
- 不同曲线使用各自有效的 X 网格；不为叠加绘图强制插值、补点或截成相同行数。
- 不同纵轴物理量或单位不能仅因为都能读成数字就直接同轴叠加。先按目标选择单位换算、分图或其他明确方案。
- 空列不作图，缺失值不补零，不跨缺失段连接。
- 保留采集顺序。存在回扫、循环或重复 X 时，不自动按 X 排序，以免改变曲线路径。
- 若已有误差列或不确定度数据，读取其定义，按本次要求保留显示；本稿“默认不显示点符号”不等于可以删除误差信息。

## 4. 坐标轴、单位与版面

### 4.1 横轴

横轴名称和单位必须来自目标数据。本稿将 XPS 结合能轴设为高值在左、低值在右；其他图型优先采用已有明确的源图方向或本次要求。缺少约定的普通 X–Y 图，暂定由左向右递增。

不同数据的横轴应分别命名，不能统一写成 `Binding Energy (eV)`。禁止继承参考 Fe 2p 的固定数值范围。

主刻度间隔按跨度设置，以便于阅读的数值为主，通常使图内有约 5—9 个主刻度。日期、分类轴或特殊坐标按实际类型处理，不套用普通数值轴间隔。

### 4.2 纵轴

Y 轴默认显示刻度数字，便于读取强度和比较数值。若本次主要展示谱形并明确要求简洁版式，可隐藏 Y 刻度及数字，同时保留测量量和单位。

轴标题写实际量及单位，例如计数率数据使用 `Intensity (counts/s)`；只有数据或处理记录支持任意单位时才使用 `a.u.`。不能把任意强度列默认理解为已经归一化。

若用户未指定范围，可先使用全部待显示曲线的有限值范围，上下各留约 8% 跨度，再根据实际预览调整。常量数据采用适合其量级的非零留白，不制造不存在的变化。

同一批需要直接比较的图，在量与单位一致时尽量使用统一的轴范围与刻度。若各图范围不同，应保证读者能够识别差异。

### 4.3 图层和尺寸

四边框使用上下左右轴线实现。字号、线宽、刻度长度以第 2 节完整页面尺寸为基准。

缩小到指定论文版面时，整体协调页面、图层、文字和线宽，检查最终尺寸下的可读性。图例需要较多空间时，可以调整图层位置或在图外留出图例区域，并记录调整。

## 5. 曲线、配色和图例

### 5.1 单曲线

按第 2 节使用深灰实线，默认不显示点符号和图例，不填充曲线下方区域。样品名可写在文件名或配套图注中。

若该样品在同一组其他图中已经有固定颜色，以一致的样品颜色映射为先，并记录所采用的映射。

### 5.2 多曲线

没有既定映射时，依次分配第 2 节的优先色：

| 曲线序号 | 本稿初始色值 | 样式 |
|---:|---|---|
| 1 | `#515151` 深灰 | 3 pt 实线，无填充 |
| 2 | `#FF4F4F` 红 | 3 pt 实线，无填充 |
| 3 | `#FF954F` 橙 | 3 pt 实线，无填充 |
| 4 | `#00AC00` 绿 | 3 pt 实线，无填充 |
| 5 | `#4FA7FF` 浅蓝 | 3 pt 实线，无填充 |
| 6 | `#804FFF` 蓝紫 | 3 pt 实线，无填充 |
| 7 | `#B94FFF` 紫 | 3 pt 实线，无填充 |

同一批图中，同一样品使用同一颜色。不要根据每张图的峰高、强度或排序临时重排颜色。

没有既定映射且曲线不超过七条时，按顺序取前 N 种颜色。超过七条曲线时，根据可辨认程度增加颜色或采用线型辅助区分，并保存映射；不直接循环使用完全相同的颜色和线型。曲线过密时先检查图页大小和分图方式，不擅自删掉样品。

普通谱线以线条表达；离散实验点若需要散点或线加符号表达，应按其数据性质设置，并记录点形、大小和是否连接。

### 5.3 图例

多曲线默认显示图例，文字使用真实样品名，顺序与绘图顺序一致。不使用含义不明的 `Book1_B`、`Col(C)` 作为最终图例。

图例使用 Arial、22 pt，去掉边框和背景块，放在不遮挡重要数据的位置。若图内没有足够空白，移到图外并协调版面；若用户要求无图例，改在图注或其他明确标签中保存样品对应关系。

## 6. 数据处理与可选展示方式

默认保留原始数值、横纵轴比例关系和采集顺序。以下操作需本次任务已经要求，或有可核对的既定处理约定：

| 操作 | 执行时要记录的内容 |
|---|---|
| 平滑 | 方法、窗口及参数；保留原始数据列 |
| 归一化 | 方法、基准、区间及处理后的轴标题 |
| 扣基线、背景校正 | 算法或背景来源，处理范围 |
| 纵向错位排列 | 每条曲线的偏移量，标记 `offset for clarity` 或等效说明 |
| 单位换算 | 原单位、目标单位、换算关系 |
| 区间截取 | 所选区间，保留完整源数据 |
| 平均与误差 | 重复测量来源、样本量、误差含义 |
| 峰位、元素或其他标签 | 用户提供或本次核实的依据 |

以上操作放在新增工作表或派生列中，保留可追溯来源。仅调整线宽、颜色和版式时，不顺带改变数据。

本规范不默认进行峰拟合、峰面积分解或组分归属。若之后任务增加了这类分析，应在明确的数据处理和模型方案下执行，再选择相应的分峰绘图规范。

## 7. Origin 执行与交付

1. 读取目标文件和相关工作表，建立样品与曲线映射，检查单位、缺失值及 X/Y 配对。
2. 依据第 2 节决定单曲线或多曲线样式；结合目标数据确定轴名称、方向和范围。
3. 使用新图页或参考模板的工作副本；套用字体和版式后，清除图页内不需要的模板谱线、组分、包络、填充和旧图例。保留源文件和来源工作表数据。
4. 加入需要显示的目标曲线，应用颜色、线型、图例及坐标设置。颜色映射在同一批输出中保持一致。
5. 保存为新的 `.opju`。若显示 N 条样品曲线，图中应有 N 条对应的数据曲线；误差对象、辅助对象另行记录。
6. 重新打开输出项目，核对数据范围、曲线数和样式。导出 PNG 并打开实际文件检查。
7. 交付可编辑项目、预览和必要的映射/处理说明；按需要另外导出 PDF、SVG 或 TIFF。

建议命名：`样品名_图型_非分峰.opju`；多样品可使用 `样品组_图型_对比.opju`。命名不应覆盖已有文件，除非用户明确要求覆盖。

使用独立可控的 Origin 会话，不关闭用户未保存的项目。导出返回成功后仍需检查实际文件存在且可打开。

## 8. 验收清单

- [ ] 源文件、源数值与已有分析数据已保留。
- [ ] 每条曲线对应正确的样品、X 列和 Y 列。
- [ ] 有效曲线数与目标样品数一致，没有遗留模板曲线。
- [ ] X/Y 轴名称、单位、范围和方向正确。
- [ ] 字体、字号、图层比例、3 pt 坐标框和曲线宽度符合参数表。
- [ ] Y 轴刻度显示方式与本次要求一致。
- [ ] 曲线按深灰、红、橙、绿、浅蓝、蓝紫、紫的优先顺序分配颜色，批次间映射一致。
- [ ] 图例使用 Arial、22 pt，图例或其他标识能明确区分样品。
- [ ] 普通曲线下方没有意外继承的渐变或组分填充。
- [ ] 没有自动添加拟合包络、组分峰、拟合背景或无依据标签。
- [ ] 缺失值没有补零，回扫或循环数据的顺序未被错误排序。
- [ ] 任何归一化、平滑、错位排列等操作均有记录。
- [ ] 输出 OPJU 可以重新打开，图形可编辑。
- [ ] 实际 PNG 已打开检查，文字无裁切，图例不遮挡重要曲线。

## 10. 初稿中便于你优先修改的项目

本稿已给出可执行默认值；以下不是执行前的必答问题，只是便于后续修改的索引：

1. 单曲线是否用深灰，还是直接使用彩色。
2. 多曲线是否继续使用当前已指定的七色顺序。
3. Y 轴刻度数字是否默认显示。
4. 多曲线图例的字号与默认位置。
5. 多曲线默认同轴叠加，还是按需求错位排列。
6. 普通曲线是否需要点符号或特殊填充。
7. 是否继续采用 3 pt 线宽及当前画布尺寸。

版式依据为同目录的 `Origin_分峰绘图格式规范_AI_README.md`；本文件为独立的非分峰规范，用户可单独修改和使用。用户已指定上述七色顺序，并确认图例使用 Arial、22 pt；其他标为“暂定”的内容仍保留为可修改的初稿设置。
