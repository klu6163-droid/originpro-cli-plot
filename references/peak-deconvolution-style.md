# Origin 分峰绘图格式规范 · AI 可直接执行

## 1. 用途与执行原则

使用本规范绘制“实验谱 + 总拟合 + 多个组分峰 + 背景”的分峰图，沿用参考 `PU-Fe_Fe.opju` 的版式，并采用用户指定的组分配色：`#FF954F → #00AC00 → #4FA7FF → #804FFF → #B94FFF`。所有组分均使用组分色到白色的渐变填充。组分配色与填充开关以此规则覆盖参考实测设置。优先交付可编辑的 Origin `.opju`，并导出预览图供检查。

本规范包含四类信息：

| 标记 | 含义 | 执行方式 |
|---|---|---|
| 用户指定 | 用户明确给出的组分优先配色与全部渐变填充要求 | 优先执行，覆盖冲突的参考实测设置 |
| 参考实测 | 从参考 OPJU 读取并与原生导出图核对过的格式 | 用于未被用户规则覆盖的样式 |
| 通用规则 | 为不同样品、不同峰数和不同谱区制定的复用规则 | 按目标数据应用，不冒充参考原值 |
| 未确认 | 自动化未能完整读出的参考细节 | 有模板时保留原生设置；不得声称从本文件得到了确切数值 |

默认执行已经拟合好的数据绘图。用户明确要求“分峰拟合并绘图”时，先完成目标数据自己的拟合，再应用本规范。仅要求“统一格式”“按此样式画图”不意味着重新拟合。

用户已给出的峰数、峰归属、样式选择、处理方式和输出要求优先；不要重复询问已明确的选择。只有会实质改变结果且无法从数据、记录或现有约定判断的信息，才需要澄清。

## 2. 先识别数据，不按固定列号套用

### 2.1 必须区分的角色

| 角色 | 推荐列名 | 要求 |
|---|---|---|
| X | Binding Energy / 实际自变量名 | 保留真实单位和数值 |
| Raw | Raw | 原始实验谱；不为美观擅自平滑或归一化 |
| Fit | Fit Envelope | 已有总拟合，或本次实际拟合产生的总曲线 |
| Component 1…N | Peak 1…Peak N / 已确认的峰名 | 峰数取决于数据，不固定为 5 |
| Background | Background | 已有或实际拟合得到的背景，不能虚构 |

读取全部相关表、列名、单位、注释、公式和有效行。识别空列、缺失值以及每条曲线的 X 网格；不要把空预留列计入峰数。注释中孤立的字母不能作为元素或峰归属证据。

对新增标准化绘图表，可使用 `X | Raw | Fit Envelope | Peak 1 | … | Peak N | Background` 的顺序。若原项目使用多个工作表或拟合曲线使用不同采样网格，保留各自 X/Y 对应关系，不必为了列顺序重采样。

### 2.2 确认组分是否已经包含背景

设背景为 `B(x)`，净组分为 `S_i(x)`，总拟合为 `F(x)`，有效组分数为 `N`。

| 数据形式 | 正确关系 | 绘图处理 |
|---|---|---|
| 组分为扣背景后的净峰 | `F = B + Σ S_i` | 若需沿背景展示组分，新建显示列 `P_i = S_i + B` |
| 每条组分已叠加背景 | `P_i = S_i + B`；`F = Σ P_i − (N−1)B` | 直接使用 P_i，不再重复加背景 |
| 全部曲线已经明确扣背景 | `B = 0`，关系以处理记录为准 | 可将零线作为明确标注的显示基准 |
| 未提供背景且处理状态不明 | 无法直接确定 | 不擅自设为零，不虚构背景线 |

原始列保持不变。任何为展示新增的列，都应写清公式和来源。数值一致性核对采用适合当前数据精度的容差；不能把参考文件的容差当成通用标准。

## 3. 固定视觉样式

### 3.1 页面与图层

以下为参考实测值，也是默认画布：

| 参数 | 默认值 |
|---|---|
| 页面 | 横向，11 × 8.5 inch，即 27.94 × 21.59 cm |
| 视觉背景 | 白色 |
| 图层左边距 | 页面宽度的 18% |
| 图层上边距 | 页面高度的 10% |
| 图层宽度 | 页面宽度的 68% |
| 图层高度 | 页面高度的 72% |
| 右边距 / 下边距 | 14% / 18% |
| 四边坐标轴 | 黑色 `#000000`，3 pt |
| 网格线 | 全部关闭 |
| 图例 | 默认隐藏；曲线对应关系保存在说明或图注中 |
| 图内大标题、峰位、价态文字 | 默认不添加；有明确需求和依据时再加 |

参考项目的页面背景实际采用“自动/无色”，图层无独立填色。使用原生模板时保留；从零创建且需要稳定白底导出时，可明确设为白色，此项属于通用实现选择。

四边框由四条坐标轴组成，不是额外画出的矩形。不要因为图层 `border` 或 `showframe` 为 0，就漏画上边、右边轴线。

字号和线宽以下述完整画布为基准。若目标另有版面尺寸要求，应整体协调画布、图层、文字和线宽；不得只缩小图层而保留超大的文字。

### 3.2 字体与刻度

| 元素 | 默认格式 |
|---|---|
| 全图字体 | Arial，以字体名称设置 |
| X/Y 轴标题 | 32 pt，黑色；保持参考常规字重外观，不额外强制加粗 |
| X 轴刻度数字 | 26 pt，黑色，不加粗、不旋转 |
| Y 轴标题 | 旋转 90° |
| 底部主刻度 | 朝外，长度 8 pt，粗细 3 pt |
| 底部次刻度 | 朝外，每两个主刻度之间 1 个 |
| Y 轴刻度及数字 | 隐藏，保留轴标题 |
| 顶部和右侧 | 仅保留轴线，隐藏刻度、数字和标题 |

参考中 Arial 对应本机字体索引 76。这个索引不能跨机器硬编码。

次刻度独立长度没有得到可靠实测值。有原生模板时继承；无模板新建时可使用 4 pt 作为本规范的补充默认值，并记录它是实现选择。

### 3.3 原始谱、总拟合、背景

| 角色 | HEX 色值 | 线型 | 线宽 | 点符号 | 填充 |
|---|---|---|---:|---|---|
| Raw | `#515151` | 实线 | 3 pt | 无 | 无 |
| Fit Envelope | `#FF0000` | 虚线 | 3 pt | 无 | 无 |
| Background | `#808080` | 实线 | 3 pt | 无 | 无 |

使用普通二维 Line Plot，以直线连接相邻有效数据点。不要为达到平滑外观，将实验谱擅自改为样条插值或删除噪声点。

### 3.4 组分配色和数量扩展

以下前五种颜色为用户指定的优先顺序，替换原有参考实测配色。每条组分的轮廓线采用对应色值，填充均为该组分色到白色 `#FFFFFF` 的渐变，包括第 4 组分。

| 组分序号 | HEX 色值 | 线型 / 线宽 | 默认填充 | 来源 |
|---:|---|---|---|---|
| 1 | `#FF954F` 橙 | 实线 / 3 pt | 组分色到白色渐变 | 用户指定 |
| 2 | `#00AC00` 绿 | 实线 / 3 pt | 组分色到白色渐变 | 用户指定 |
| 3 | `#4FA7FF` 蓝 | 实线 / 3 pt | 组分色到白色渐变 | 用户指定 |
| 4 | `#804FFF` 蓝紫 | 实线 / 3 pt | 组分色到白色渐变 | 用户指定 |
| 5 | `#B94FFF` 紫 | 实线 / 3 pt | 组分色到白色渐变 | 用户指定 |
| 6 | `#00A7B5` 青 | 实线 / 3 pt | 组分色到白色渐变 | 通用扩展色 |
| 7 | `#D65F8D` 玫红 | 实线 / 3 pt | 组分色到白色渐变 | 通用扩展色 |
| 8 | `#8C6D46` 棕 | 实线 / 3 pt | 组分色到白色渐变 | 通用扩展色 |

- 没有既定组分颜色映射时，按上述优先顺序分配；峰数少于 5 时取前 N 种颜色，只画实际存在的组分，不保留假的峰或图例项。
- 峰数大于 5 时，先使用完上述五种优先色，再采用第 6—8 种扩展色；超过 8 个组分需扩展配色并保存完整映射，不能循环成无法分辨的重复颜色。扩展组分也统一使用组分色到白色渐变。
- 同一批样品中，已确认的同类组分尽量保持相同颜色；不要按每个样品的峰高重新分配颜色。
- 没有化学归属时，沿用源组分顺序并使用中性名称。颜色本身不代表价态或键型。
- 所有有效组分默认开启渐变填充，第 4 组分没有例外。载入原生模板后，应主动应用本节的配色和填充开关，避免模板旧设置覆盖用户要求。

## 4. 随目标数据调整的设置

| 项目 | 通用规则 |
|---|---|
| XPS 横轴 | `Binding Energy (eV)`，高结合能在左、低结合能在右 |
| 其他谱图横轴 | 按实际自变量、单位和领域表达设置；不自动套用 Binding Energy |
| X 范围 | 取目标数据或用户指定谱区，禁止复制 Fe 2p 的数值范围 |
| X 主刻度间隔 | 按跨度选便于阅读的间隔，通常使图内约有 5—9 个主刻度；不是固定 5 eV |
| Y 范围 | 包含所有需要显示的曲线并留适量上下空间；不强制从零开始 |
| Y 标题 | 按实际量和单位设置，如 `Intensity (counts/s)` 或确有依据的 `Intensity (a.u.)` |
| 归一化、平滑、扣背景 | 只按已有处理记录或用户要求进行，并保留未处理数据 |
| 峰数与模型 | 由目标数据和科学依据确定，不从参考样式推断 |
| 缺失值 | 保留缺失；不补零，不跨缺失区人为连接或填充 |

若没有既定 Y 范围，可用全部可见曲线的有限值求最小/最大值，并在上下各加约 8% 跨度作为起始留白；这是布局规则，最终应检查实际显示。

参考图写 `Intensity (a.u.)`，但源工作表单位为 `Counts/s`。本规范采用“目标数据真实单位优先”的规则，不把这项单位不一致复制到新图。

## 5. 填充规则：必须明确基准曲线

### 5.1 渐变方式与当前覆盖规则

参考已开启填充的组分使用以下渐变机制。当前规范按用户要求将这一机制应用于全部有效组分，组分颜色以第 3.4 节为准：

| 参数 | 读数 | 含义 |
|---|---:|---|
| `pf` | 1 | 启用填充 |
| `pfv` | 8 | Fill to next data plot – One Color |
| `pfn` | 1 | Common X Area |
| `pfm` | 3 | Two Colors，双色渐变 |
| 渐变颜色 | 组分颜色、白色 `#FFFFFF` | 不是单一色值 |
| 线条透明度 | 0% | 不代表渐变色端点透明度也已确认 |

其中 One Color 是曲线间填充类别的名称，Two Colors 是填充内部的渐变方式，两者并不矛盾。

未确认项包括：参考渐变端点 alpha、渐变方向，以及 D/E/F 三条参考组分的明确填充目标列。已读到这三条曲线的 `lfp` 原始偏移分别为 3、2、1，但不得未经解析就认定全部填到背景。H 的 `lfp=0`，已确认填至下一条 I/Background。

### 5.2 用于新分峰图的明确规则

1. 对叠加背景展示的组分，默认从该组分的显示曲线填至**目标数据自己的背景曲线**；这是本规范的通用绘图规则，不是对未确认参考终点的断言。
2. 对明确扣背景后的组分，可填至零基准。基准若为辅助列，要标注为显示用途，不能冒充拟合所得的背景。
3. 把每条填充曲线的目标写入映射，例如 `Peak 2 display → Background`。不要直接复制原图的 `lfp=3/2/1`。
4. 添加、移除或重排曲线后，重新读取并检查填充目标。软件若只能填到下一条曲线，可创建引用同一背景的辅助曲线实现配对，并隐藏辅助线和辅助图例；不能修改真实背景数据。
5. 填充只覆盖有共同有效 X 数据的区间。若不同曲线网格不一致，应先确认软件的显示处理，不能静默改写原数据。
6. 所有组分开启渐变填充，第一色使用用户指定的对应组分色，第二色为白色。模板可用于保留尚未完全读出的渐变方向和端点透明度等细节，但不能恢复旧配色或关闭某一组分填充；不要未经核实把“浅色”改写成某个固定透明度百分比。

原生模板不可用时，按已确认参数可重建主体风格。渐变方向、端点透明度等细节应标记为新建图的实现选择，并以预览图检查遮挡；不得称为对原图填充的精确复刻。

## 6. 绘图顺序与 Origin 执行流程

默认曲线顺序：`Raw → Fit Envelope → Component 1…N → Background`。这是原图顺序。原图中部分总拟合线会被后绘制的组分遮住；若需要把总拟合置于最上层，应记录为可读性调整，并在调整后再次核对填充目标。

1. **读取输入**：识别已有拟合还是原始谱，记录各条曲线的来源、单位、有效点数和处理状态。
2. **保护源文件**：参考和输入以只读方式检查；写入新的输出目录。中文路径若影响 Origin 自动化，可使用 ASCII 暂存副本。
3. **确定映射**：保存 `X / Raw / Fit / Components / Background` 对照，以及组分是否带背景的判定。
4. **如需拟合**：仅在本任务明确包含拟合时进行。根据目标谱区选择模型、背景和约束；保留拟合记录、残差和实际得到的统计量，不复制参考峰位或价态。
5. **应用模板与用户配色**：模板可用时优先复用其页面、图层、字体和线型，再按第 3.4 节覆盖所有组分的颜色和渐变填充开关。清除模板的参考数据依赖，替换为目标曲线；所有隐藏辅助对象也应核对。
6. **调整曲线数和坐标**：有 N 个有效组分且 Raw/Fit/Background 齐全时，科学数据曲线应为 `N+3` 条；辅助曲线另行记账。背景缺失时不能为了凑数增加假曲线。
7. **重建填充映射**：逐条明确目标背景/零基准，避免沿用旧偏移。
8. **保存并重新打开**：生成新的 `.opju`，重新打开核对工作表、有效点数、曲线数量、范围、标签和样式。
9. **导出并目视检查**：至少导出一张宽 1800 px 的 PNG 预览，打开实际文件，检查文字、曲线遮挡、渐变、裁切和填充终点。发表所需 PDF/SVG/TIFF 另按要求导出。
10. **交付说明**：列出 OPJU、预览图、曲线映射和必要的处理/拟合记录。明确哪些是用户指定、参考继承、目标自适应或补充设置。

使用独立可控的 Origin 会话，不接管或关闭用户未保存的项目。若遇到会话失效或导出失败，保留已提取的数据和证据，避免无限重试；没有真实可打开的文件就不能宣称完成。
